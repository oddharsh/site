# Explore map: B (finish content-hash migration) + A (guard silent-failures) + C (verified-understanding close)

Walked B, then A, then C. All decisions below were shown and chosen in front of
the user; nothing closed off-screen.

## Quadrant 1: Known knowns (settled ground, cited)

- Request path is exact `ROUTES.get()` then ordered `PREFIX` then static
  fallthrough (`index.js:160-172`). The load-bearing coupling: `wrangler.jsonc`
  `run_worker_first` must mirror `index.js`, or a route silently goes static
  (`index.js:2-4`).
- Caching: `swrKV` (two-key SWR, empty-rebuild guard) + `cachedRender`
  (edge, 200-only put) + the 404 clamp under `/images/*` (`lib/assets.js:23-39`).
- Images: `/i/<stem>.<hash8>` immutable, `/images/<thumb>` 301s in
  (`index.js:230-249`). `hashes.json` is 146/146 complete, so the legacy `?v=`
  path is dead code.
- Shell: `nav.js` adopts a static desktop partial generated by evaling nav.js's
  own data (`gen-desktop-partial.mjs:36-49`); `luna.css` is the extracted OS.
- Deploy: `build.mjs` minifies 3 shells with throw-to-fail tripwires
  (`build.mjs:47-49`); `bump-version.sh` logs D1 checkpoints (the single source
  both `/updates` and `/restore` read) with replica-lag retry.

## Quadrant 3: Unknown knowns (taste, extracted)

- Delete dead ritual, keep cheap live guards. (`THUMB_VERSION` out; `absThumb`,
  `REMOVED_STEMS`, the 404 clamp, the sw stub all stay.)
- Veto at deploy, not detect at runtime. Guards live in `build.mjs`, the one
  reliable path, because Workers Builds CI has silently skipped pushes.
- Harden the invisible regressions, note the rare edges.
- Solo maintainer; a flaky tripwire that blocks the deploy gets commented out,
  so every hard-block check must be zero-false-positive.
- View Source is sacred: checks read files and may fail the deploy, never touch
  served bytes.

## Quadrant 4: Unknown unknowns (landmine cards)

- **L1 (DECIDED: a).** Retiring `THUMB_VERSION` is a behavior fork, not a
  deletion (`photos.js:225-227`). On a stem missing from `hashes.json`, the
  builder must SKIP the stem from the manifest and `console.log` it, so no
  broken `/i/undefined.avif` tile ever ships.
- **L2 (SHARP EDGE).** The legacy fallback lives in 4 consumers, not 1:
  `home.js:142`, `photos.js:266`, the inline grid `index.html:1068-1069`
  (its own `vq` reconstruction), plus a stale comment `masonry.html:165`.
  B is a 4-file edit + a comment fix.
- **L3 (DECIDED by design).** The allowlist has 13 globs; `index.js` is exact
  keys + regex PREFIX. A symmetric diff false-fires on every glob. The check is
  directional: every EXACT `ROUTES` key must be in the allowlist. Globs/PREFIX
  get a one-time correspondence note, not an assertion.
- **L4 (SHARP EDGE, folds into A).** cal emits no CSP. The CSP check is
  conditional: IF a response sets a `style-src`, it must include `'self'`.
- **L5 (DECIDED, ride-along fix).** The "byte-identical to nav.js's app-shell
  rules" comments (`chrome.js:43`, `writing.js`, `serendipity.js`, cal) point at
  CSS that moved to `luna.css` in phase A. The geometry-sync check's canonical
  is `luna.css`; A corrects the comments to say so.
- **Pinned for C.** The blink fix is 3 substrings across 2 blocks: `luna.css:353`
  (desktop groups `mix-blend-mode:normal`), `:368` (`image-pair(axp-window)
  {isolation:auto}`), `:369` (window old/new `mix-blend-mode:normal`).

### Sharp edges recorded (awareness, no code)
- Stale-`luna.css` cache window: if `/luna.css` 404s, `nav.js:214-218` injects a
  link with no retry. Mitigation is cache posture, not code.
- The speculation-rules exclusion list grows by hand when a new dynamic route
  lands. No guard proposed; note when adding routes.

Safari 27, through this site's lens

WWDC26 shipped Safari 27 (in macOS 27 “Golden Gate,” iOS/iPadOS 27, visionOS 27) — ~58 new web-platform features. A bunch of them are things this site already leans on, so this page is the “the platform caught up” cut, not the full changelog. Authoritative source: the WebKit team's News from WWDC26: WebKit in Safari 27 beta.

Each card is tagged with what Safari 27 brings, plus a live check of your browser below. The site's whole bet is high-octane fuel: when the engine supports a feature it burns it, otherwise it falls back — so “not in your browser” never means broken.

appearance: base-select now stable

Style a real <select> — and its dropdown — with CSS, no JS rebuild and no accessibility loss. Safari 27 takes it stable and adds the ::picker-icon and ::checkmark pseudo-elements.

On this site: the homepage and the horizon demo already ship a Luna-styled base-select with a beveled drop-button — behind an @supports guard, so non-supporting browsers get the native dropdown. Safari going stable means more visitors see the styled one with zero code change here.

Anchor positioning upgrades Safari 27

Safari 27 makes anchored elements follow transformed positions, and adds position-anchor: normal | none plus refined anchor-valid / anchor-visible matching.

I'm pinned to that button with position-anchor + anchor() — no JS measuring. In Safari 27 I'd track it even through CSS transforms.

On this site: the photo/track tooltips use CSS anchor positioning as the JS-free keyboard fallback. Transform-aware anchoring matters here because windows move via transform (drag) — an anchored popover can now stay glued to a dragged element.

Scroll anchoring Safari 27

When content loads above the viewport, the browser keeps your scroll position instead of jumping. Controlled with overflow-anchor.

On this site: every page is a pinned window whose .content scrolls internally. Late-arriving content above the fold (a lazy image, the server-injected tracklist) is exactly the jump scroll anchoring prevents — now native in Safari, no JS scroll-restoration needed.

The :heading pseudo-class Safari 27

Match <h1>–<h6> in one selector instead of enumerating them (and one day :heading(2,3) for levels).

If your browser has :heading, this is green.

So is this one — one rule, every level.

(Body text stays the default color.)

On this site: a small win — the design tokens style captions/headings with one stack today; :heading would let the shared nav.js CSS touch every page's headings without knowing their tag.

CSS odds & ends Safari 27

A grab-bag that tidies things we hand-roll:

width: stretch;          /* fill the container, margins accounted for  */
color: revert-rule;      /* roll one cascade rule back, not the whole property */
contain: style;          /* scope CSS counters / quotes to a subtree    */
color: oklch(... );      /* + new srgb-linear / display-p3-linear spaces */

On this site: contain: style is the honest version of the quote/counter scoping we avoid; the linear color spaces pair with the OKLCH + P3 work already in the homepage.

Platform & worker upgrades Safari 27

Less visible, more structural:

  • Top-level await — full ESM loader rewrite for standards compliance.
  • WebAssembly JSPI — synchronous Wasm can suspend and await JS promises.
  • Service Worker static routing — declare routing rules that bypass the SW entirely.
  • Transferable streams + ReadableStream.from() + async iteration.
  • Cookie Store API maxAge.

On this site: Service Worker static routing is interesting for sw.js — the cache-first/SWR/network-only split is currently JS in the fetch handler; static routes could declare some of it and skip waking the worker at all.

Spatial web Safari 27

The <model> element graduates from visionOS-only to iOS, iPadOS, and macOS; visionOS 27 adds immersive website environments and spatial-photo controls on <img>.

On this site: not used (no 3D), but filed — a resto-mod car site has obvious one-day uses for a real <model> viewer.

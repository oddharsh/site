Tooltip Experiments

Cursor-following tooltip styles for the photo grid + tracklist on aadhar.sh. Hover the slots and rows to see them in motion. All three sections below use the same modern stack: popover API for show/hide, @starting-style for the entry fade, and a tiny rAF-coalesced translate3d loop for cursor tracking — about ~100 lines of JS for the whole system.

Fuji X-T LCD readout (photos)

Hover any slot. Floating panel mimics the camera's image-review screen — histogram band on top, then filename, exposure trio, recipe grid, footer. Follows the cursor. The actual photo stays right there in the slot (no mini-thumbnail in the panel — the larger one is already visible).

Vinyl sleeve at cursor (tracks)

Hover any row. A square album cover with a paper-mat border and a slight −6° tilt floats at the cursor, like you're pulling a sleeve out and tilting it to read the front. Same architecture as above — popover API + cursor tracking + entry fade. The row text stays put.

  1. 3:54 Guild (feat. Mac Miller)—Earl Sweatshirt, Mac Miller
  2. 2:14 GAHDAMN—Kairee Doty
  3. 4:49 1995—Freddie Gibbs, The Alchemist
  4. 3:35 TRICERATOPS—Action Bronson, Paul Wall, Lil Yachty
  5. 2:04 GREEN LIGHT—colle$ttye

Note: in production this would use the actual album art URL from each track's data-track-image attr (already inlined server-side). For the demo here we substitute a solid color per row.

CSS Anchor Positioning (no cursor following)

Element-anchored rather than cursor-anchored. Included for comparison — the modern web platform's pure-CSS answer for tooltips that don't need to track the cursor. Useful as a JS-disabled fallback path.

⚠ Your browser doesn't support anchor-name yet — Chrome 125+ or Safari TP required to see this demo.

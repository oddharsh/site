Tooltip Experiments v2

Four alternative tooltip styles. The Fuji LCD style has been re-done as a separate floating panel (cursor-following) that mimics the camera's image-review screen layout — thumbnail + histogram + recipe data, with the photo slot itself staying untouched.

#1 — Fuji X-T LCD review tooltip (cursor-following, popover API)

Hover any slot below. A separate floating panel appears at the cursor, mimicking the camera's image-review screen (thumbnail + histogram + shooting params grid). Photo stays clean. The panel uses the native popover attribute (no manual display:block management) and @starting-style for the fade-in, with cursor-tracking via requestAnimationFrame. ~80 lines JS total — about a quarter of the current tooltip IIFE.

#3 — Vinyl sleeve emerging from row (CSS-only, no JS)

Hover a row, album sleeve emerges from the right edge with a slight tilt. Pure CSS transform + transition.

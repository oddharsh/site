Tooltip Experiments

Four alternative tooltip styles, each illustrated on real photos and a sample tracklist. Hover the slots / rows to see each style in motion. Touch devices show nothing (none of these have a useful touch-mode).

#1 — Fuji X-T LCD viewfinder

Hover overlays a camera-style HUD on the photo: film simulation badge top-left, exposure triplet bottom-left, focal length bottom-right, faint rule-of-thirds grid + center crosshair. Honors the actual X-T5 you shoot on. CSS-only — no JS needed, ~40 lines of styling.

● REC CLASSIC NEG 100% F4.0 · 1/250 · ISO3200 +3 SAT · GRAIN STR/SM XF18 27mm
● REC PROVIA 100% F2.0 · 1/640 · ISO320 −0.3 EV · DAYLIGHT XF35 53mm
● REC ACROS+R 100% F5.6 · 1/125 · ISO800 CHROME +1 BLUE +2 XF56 84mm

#3 — Vinyl sleeve emerging from row

Hover any track row and an album sleeve pulls out from the right edge of the row with a slight tilt. Pure CSS transform + transition, ~30 lines. Doesn't cover the photo grid above or other rows; just sits to the right of the row itself.

  1. 3:54 Guild (feat. Mac Miller)—Earl Sweatshirt, Mac Miller
  2. 2:14 GAHDAMN—Kairee Doty
  3. 4:49 1995—Freddie Gibbs, The Alchemist
  4. 3:35 TRICERATOPS—Action Bronson, Paul Wall, Lil Yachty

#4 — Polaroid flip

Hover flips the photo 180° via transform: rotateY. The back is cream paper with EXIF written in italic Georgia like handwritten notes. Pure CSS, no JS. The slot becomes its own tooltip — no separate floating panel.

#5 — CSS Anchor Positioning

Modern CSS-only: each slot gets an anchor-name, each tooltip has position-anchor + position-area. The browser auto-positions the tooltip relative to the hovered slot with edge-aware fallback via position-try. Requires Chrome/Edge 125+ or Safari 26 TP.

⚠ Your browser doesn't support anchor-name yet — Safari Tech Preview or Chrome 125+ required to see this demo.

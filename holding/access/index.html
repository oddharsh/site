Access

Access to inputs has defined AI as we use it. Not the weights, not the benchmark: what the model is allowed to touch. This is that map, drawn as the one Windows app that was already a tree of what a machine can reach.

Thirty-one nodes. Each one is a flavor of access, not a product, so a node outlives the vendor that currently occupies it. Products hang off the nodes as examples. Four states, straight out of Device Manager: installed, yellow bang for a device that half works, unknown device for one that's present with no driver, and disabled for one nobody has shipped at all.

    Why access, and not capability

    Model generalization is worse than it looks from the outside. Pattern matching across that many dimensions builds correlations out of bad priors and coincidence, and correlation still isn't causation. So the reliable way to make a model right about a specific situation isn't a better prior. It's handing it the situation.

    That reframes every node on this board. Access isn't a convenience layer bolted onto intelligence. It's the substitute for the generalization the model doesn't have, which is why one log line beats a day of careful reasoning about what the bug probably is, and why Feedback is the most underbuilt branch here.

    Trust is the gating dependency

    The vertical axis is blast radius, from reading what it's handed to moving atoms. Every rung up buys capability and spends trust, and that's why the top of the board is thin: the blockers up there aren't engineering, they're authorization. Secrets, identity, and money are one dependency chain, and Cloudflare wiring agentic commerce onto the same Web Bot Auth it uses to sort crawlers is that chain showing up as a roadmap.

    The gaps are the interesting part

    Eight devices carry a yellow bang, six have no driver at all, and two nobody has built. A few of those are genuinely hard. Most are unbuilt because the thing they'd need is a standard, an index, or somebody's permission, and no single vendor can ship any of the three alone.

    the one path that isn't a dependency

    Prompt injection isn't a node on this board, and it isn't an edge either. Turn on Trace the injection path and the flow doesn't route through the graph, it routes through the context window, because that's where untrusted tokens and privileged actions actually meet. Every arrow into that box is a page an agent fetched. Every arrow out is something it can do. Nothing in the dependency structure separates them, which is the whole problem, and it's why Secrets is the node where the good answer turned out to be never letting the agent read the credential at all.

In the way: phase 3 hands dictionary generation to the network, which means the CDN, not you, learns which of your resources change and how.     Inference speed unknown devicereads what it's handed2026reasoning tokens Speed decides which access is affordable, so it belongs on this board even though it isn't a permission. In the way: nothing conceptual, it's a cost curve, which is exactly why it moves fastest. Cerebras and Groq inference, batch versus interactive pricing
    Tool calls installedchanges its own machine2023context window Where workflow skeuomorphism came from.     Tool discovery yellow bangchanges its own machine2026tool calls A model can only call what it can find, and what a given tool means shifts from one model to the next, so the same server behaves differently depending on who mounted it. In the way: no index. Every host ships its own roster and hopes the descriptions carry. The teams treating tool descriptions as an audience-facing surface, the way Resend does, are early to something real. MCP registries, tool search, deferred tool schemas
    Code execution installedchanges its own machine2024tool calls Code mode: write one program instead of chaining forty calls. The largest single jump on this board, because it converts every other access from a menu into a language. Code interpreter, sandboxed isolates, Worker Loader
    File system installedchanges its own machine2025code execution Durable state the model can name, list, and revise. Enough of a memory that the context window stops having to be one. Coding agents, workspace mounts, artifact directories
    Computer use yellow bangchanges someone else's2024code execution Access to your cursor, which is the universal adapter: anything a person can do, in any app, with no integration. In the way: it runs at pixel rate, it has no undo, and it can't prove what it did afterward, so the audit trail is a screen recording. Computer use, desktop automation, RPA that finally works
    CLIs as the agent interface unknown devicechanges someone else's2026code execution, file system The most underrated bet on this board. A CLI is a typed, composable, auditable API that already ships docs, a man page, exit codes, and a dry-run flag, and it costs a company far less than a bespoke agent surface. That DoorDash, which spent years hostile to automation, now ships one is the tell. In the way: distribution and trust, not design. Every CLI is also a local binary somebody has to authorize. dd-cli, in beta July 2026 with a Claude checkout demo; webcmd; gh; wrangler
    Binaries without source disabledchanges its own machinenot yetcode execution A counterfactual worth taking seriously: without access to code, but with access to binaries, agents would live in decompilers, traces, and differential testing, and the whole toolchain would look different. Parts of that world already exist for anyone working on software they can't read. In the way: no corpus, no training signal, and no reward model for a task whose ground truth is behavior rather than text. Decompilers in a loop, strace and dtrace as context, fuzzing harnesses
    Tests and logs in the loop installed, underusedchanges its own machine2025code execution Access to cause and effect, which is the cheapest thing on this board and the least deliberately built. Handing an agent the failing test and the log did in minutes what days of reasoning about the probable bug did not, because it replaces a prior with an observation. Test runners in the agent loop, log tailing, CI output as context
    Eval and RL environments yellow bangchanges someone else's2026tests and logs in the loop First and second-order effects from causes, in practice rather than in theory. This is what training runs on, and it's the sharpest asymmetry on the board: labs have rich environments, and the person with the actual codebase has almost none. In the way: an environment is a product nobody sells you for your own system, so the people with the best ground truth can't feed it back. RLVR, verifier environments, GRPO training loops
    Correctness, formally unknown devicechanges someone else's2026code execution, tests and logs The only access on this board that returns a proof instead of a sample, which makes it the honest answer to weak generalization. In the way: specification hacking. A model that writes the spec will write a weak one that compiles, so the verifier certifies a claim nobody wanted. The Lean literature has a name for it because it happens reliably, and the bug relocates from the proof into the statement, where it's much harder to see. Lean 4 and Mathlib, autoformalization, FormaRL's compiler-plus-semantic reward; this site's Lean explainer is about exactly that relocation
    Intermediate state yellow bangchanges its own machine2026tests and logs in the loop Not the input and not the answer: the values in between. A debugger's worth of access, where most of the diagnostic signal actually lives. In the way: nothing exposes it in a shape a model can read, so agents reconstruct state by adding print statements like everyone else. Time-travel debuggers, span attributes, replay logs
    Chat output installedreads what it's handed2022context window The output access that mattered most, because it got everyone who doesn't code in the door. Access to inputs decided what models could do; this decided who got to ask. The chat box, and everything downstream of it
    Markdown and HTML installedreads what it's handed2023chat output Output a machine parses and a person reads, in one artifact. Underrated as an access story: it's why an agent can hand its work to another agent without inventing a protocol. Rendered markdown, artifacts, the markdown twin of this page
    Image output installedreads what it's handed2024chat output The social-sentiment unlock. Nothing moved public belief about what these systems can do like pictures did, including things text models had been able to do for a year. Image generation and editing, diagrams, charts
    Structured output installedreads the world2024markdown and HTML Output the caller can depend on without parsing prose. The node that turns a model from a thing you read into a thing you can put in a pipeline. JSON schema output, tool result contracts, forced tool calls
    Secrets yellow bangspends2026file system The agent needs the credential's power without the credential's value, and the good answer turned out to be never handing over the value at all. Infisical's is a TLS-intercepting, credential-injecting proxy, so a compromised agent has no secret to leak because it never held one. In the way: prompt injection sets the bar. If the agent can read the key, so can the page it just fetched. Infisical Agent Vault, April 2026, with Agent Proxy GA on 30 July 2026; ironrun
    Verifiable identity unknown devicechanges someone else's2026fetch and scrape A good bot and a bad bot are the same HTTP request until somebody signs it, which is why blocking and enabling are one problem rather than two. The interesting version isn't detection, it's routing: see an agent, hand it the agent path. In the way: the bypass market, and the fact that no site can afford to trust a signature it can't price. Web Bot Auth, which this site publishes a JWKS for; Cloudflare's 15 September 2026 deadline to split search crawlers from AI crawlers; detection at roughly $0.05 a check
    Money unknown devicespends2026secrets, verifiable identity Cloudflare's Act IV is access and commerce, and it rides the same Web Bot Auth as the crawler story. That isn't a coincidence, it's the dependency: an agent can't be trusted to pay until it can be identified, and it can't be identified until somebody signs for it. In the way: liability. Every party wants the agent's transaction and nobody wants its chargeback. x402, Turnkey, Cloudflare with the major payment networks, dd-cli completing a real checkout
    Meatspace disabledmoves atomsnot yetmoney, computer use The one branch where a wrong action can't be rolled back, which is why it sits alone at the top and why the gap between it and everything below is the largest on the board. In the way: no undo. Every other node's safety story leans on reversibility, and this is where that runs out. Robotics, physical delivery, anything holding a key to a door

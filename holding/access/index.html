Access

Access to inputs has defined AI as we use it. Not the weights, not the benchmark: what the model is allowed to touch. This is that map, drawn as the one Windows app that was already a tree of what a machine can reach.

Thirty-six nodes. Each one is a flavor of access, not a product, so a node outlives the vendor that currently occupies it. Products hang off the nodes as examples, and every node that isn't finished carries a dated bet.

Five states, all of them Device Manager's own. Installed works and something depends on it. A yellow bang works badly enough to matter. An unknown device is present on the bus with no driver, which is where somebody is actively building. Disabled is the one worth reading twice: in Device Manager a red X never meant missing, it meant switched off, which is exactly what an access looks like after the ecosystem passed it over. And a device can be not present at all, describable but attached to nothing, which is where the speculation lives. Those are hidden until you ask for them, under View.

Dates are month-level where the month is establishable and year-level where it isn't, marked with a ~. I would rather show you a coarse date than a confident wrong one.

    Why access, and not capability

    Model generalization is worse than it looks from the outside. Pattern matching across that many dimensions builds correlations out of bad priors and coincidence, and correlation still isn't causation. So the reliable way to make a model right about a specific situation isn't a better prior. It's handing it the situation.

    That reframes every node on this board. Access isn't a convenience layer bolted onto intelligence. It's the substitute for the generalization the model doesn't have, which is why one log line beats a day of careful reasoning about what the bug probably is, and why Feedback is the most underbuilt branch here.

    Trust is the gating dependency

    The vertical axis is blast radius, from reading what it's handed to moving atoms. Every rung up buys capability and spends trust, and that's why the top of the board is thin: the blockers up there aren't engineering, they're authorization. Secrets, identity, and money are one dependency chain, and Cloudflare wiring agentic commerce onto the same Web Bot Auth it uses to sort crawlers is that chain showing up as a roadmap.

    The gaps are the interesting part

    Eight devices carry a yellow bang, six have no driver, three are switched off, and four are not present at all. A few are genuinely hard. Most are unbuilt because the thing they'd need is a standard, an index, or somebody's permission, and no single vendor can ship any of the three alone.

    The two states people skip are the ones I'd look at first. Switched off is where the ecosystem already built the thing and then declined to use it: structured data has been sitting in pages since 2011 and agents read the rendered text anyway. That's a fifteen-year-old answer nobody wanted, and knowing why is worth more than another proposal. Not present is the opposite, an access precise enough to describe and attached to nothing, which is the only honest place to speculate.

    So every unfinished node carries a bet, with a date and a confidence I'm willing to be wrong about in public. High confidence means I'd argue it now. Low means it's a shape I can see and a timeline I can't. The bets are the speculative part of this page and they're labelled everywhere they appear, because a map that quietly mixes forecast into fact is worse than no map.

    the one path that isn't a dependency

    Prompt injection isn't a node on this board, and it isn't an edge either. Turn on Trace the injection path and the flow doesn't route through the graph, it routes through the context window, because that's where untrusted tokens and privileged actions actually meet. Every arrow in is a page an agent fetched. Every arrow out is something it can do. Nothing in the dependency structure separates them, which is the whole problem, and it's why Secrets is the node where the good answer turned out to be never letting the agent read the credential at all.

    Eval and RL environments yellow bangchanges someone else's~2026tests and logs in the loop First and second-order effects from causes, in practice rather than in theory. In the way: an environment is a product nobody sells you for your own system, so the people with the best ground truth can't feed it back. Bet: environments-as-a-service is the gap most worth building into, and the first credible version is bought rather than built, by a lab that wants the ground truth more than the revenue.     Correctness, formally unknown devicechanges someone else's~2026code execution, tests and logs The only access on this board that returns a proof instead of a sample, which makes it the honest answer to weak generalization. Bet: autoformalization gets good before specification review does, which is the dangerous ordering. Expect a stretch where proofs are cheap and nobody can tell whether the statement says what they meant.     Intermediate state yellow bangchanges its own machine~2026tests and logs in the loop Not the input and not the answer: the values in between. A debugger's worth of access, where most of the diagnostic signal actually lives. In the way: nothing exposes it in a shape a model can read, so agents reconstruct state by adding print statements like everyone else. Bet: the fix is boring and arrives through tracing rather than debuggers. Spans already carry the shape; what's missing is a convention for handing them to a model, and conventions arrive faster than tools. Time-travel debuggers, span attributes, replay logs
    Replayable execution disabledchanges its own machine~2014code execution Record a run once, then replay it as many times as you like, deterministically, and step backwards through it. This has existed and worked for over a decade. Passed over because: recording costs something up front and re-running was always cheap enough, so almost nobody paid. Agents inherited that habit and add print statements instead. Bet: gets rediscovered once agent turns are expensive enough that re-running to reproduce costs more than recording would have. That crossover is close, and this is the passed-over node I'd expect to come back first. rr, Mozilla, ~2014; Replay.io; deterministic simulation testing
    The discard pile not presentreads the worldnot yettests and logs in the loop Every repository is a survivorship-biased record. A model sees the approach that landed and never the four that were tried and thrown away, which is precisely the knowledge that would stop it proposing them again. Bet: the first team that deliberately keeps its failures and feeds them back gets a real edge, and nobody outside will be able to see it. Hard to build because it means choosing to store what everybody currently throws away, and the value only shows up months later. Nothing ships this. Abandoned branches, closed PRs, and reverted commits are the raw material sitting unused

    Secrets yellow bangspendsApr 2026file system The agent needs the credential's power without the credential's value, and the good answer turned out to be never handing over the value at all. Bet: signed agents win, because both sides want it. Sites want to price access and agents want to stop being blocked. Every party wants the agent's transaction and nobody wants its chargeback. Bet: not this decade at any scale that matters, and the binding constraint stays undo rather than dexterity. The first real deployments will be places where a mistake is cheap and boring.
